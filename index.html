This is where every new withdrawal request gets posted. It was never set before, which is why no notifications were arriving.

Setup checklist:
1. Add your bot as an admin of this channel/group, with permission to post messages.
2. For a public channel, use its @username. For a private channel/group, use its numeric ID (starts with -100) — forward any message from it to @userinfobot to get the ID.
3. Save it here, then tap Send Test Notification — if it fails, the error message below will tell you exactly why (e.g. bot not in channel, no permission, wrong ID).
